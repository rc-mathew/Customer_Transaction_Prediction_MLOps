# Customer Transaction Prediction - End-to-End MLOps

An end-to-end machine learning project for customer transaction prediction, covering model development, evaluation, deployment, CI/CD, containerization, monitoring, fairness, calibration, and cloud deployment.

## Planned MLOps Components

- Data preprocessing and feature engineering
- Model training and evaluation
- ROC-AUC and classification metrics
- Probability calibration
- Fairness evaluation
- REST API deployment
- Automated testing
- Docker containerization
- CI/CD with GitHub Actions
- Kubernetes deployment
- Data and model drift monitoring
- Cloud deployment
